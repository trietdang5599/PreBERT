# DeepBERT

## Instructions to Run the Source Code

In this study, we use Stanford CoreNLP. Please make sure the device has the required model installed and that `JAVA_HOME` is set up properly on the device.

After that, run the `requirements.txt` file to install the necessary dependencies. Finally, execute the `evaluation.py` file to evaluate the model. The source code includes the extracted review text feature from the AB Amazon dataset.
